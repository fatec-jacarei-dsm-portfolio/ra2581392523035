## Portfólio Web React + TypeScript
Este repositório agora inclui um portfólio web moderno implementado com React, TypeScript, HTML e CSS.

### Para rodar localmente
```bash
npm install
npm run dev
```

### Para gerar o build
```bash
npm run build
```

### Estrutura principal
- `index.html` — página inicial
- `src/main.tsx` — ponto de entrada React
- `src/App.tsx` — componentes do portfólio
- `src/styles.css` — estilo inspirado nas imagens fornecidas
